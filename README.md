# How to add the rounded corner items for .NET MAUI ListView(SfListView)?

The [.NET MAUI ListView](https://www.syncfusion.com/maui-controls/maui-listview "https://www.syncfusion.com/maui-controls/maui-listview")  allows you to customize the item appearance, such as adding rounded corners, using the [Frame](https://learn.microsoft.com/en-us/dotnet/maui/user-interface/controls/frame) layout in the [ItemTemplate](https://help.syncfusion.com/cr/maui/Syncfusion.Maui.ListView.SfListView.html#Syncfusion_Maui_ListView_SfListView_ItemsSource) property.

Define the CornerRadius property for the Frame to apply rounded corners to the items.

![Rounded corners for items in .NET MAUI ListView (SfListView)](https://www.syncfusion.com/uploads/user/kb/maui/maui-2065/maui-2065_img1.png)

Download the complete sample on [GitHub](https://github.com/SyncfusionExamples/add-rounded-corner-for-.net-maui-listview-items)
